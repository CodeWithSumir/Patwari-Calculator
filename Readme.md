# Patwari Calculator

A calculator app for Patwari work.

## Download

[Download Patwari-Calculator.apk](https://github.com/CodeWithSumir/Patwari-Calculator/releases/download/v1.0/Patwari-Calculator.apk)

## How to install

1. Open the download link on your Android phone.
2. Tap "Download anyway" if the browser shows a warning.
3. Open the downloaded APK file.
4. Allow "Install unknown apps" for your browser or file manager when asked.
5. Tap Install, then Open.
